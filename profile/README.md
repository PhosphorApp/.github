# Phosphor

**A media player and jukebox for virtual pinball cabinets — and a capable stand-alone desktop media player.**

Phosphor plays music videos across a cabinet's screens (playfield, backglass, topper, DMD)
with audio-reactive animated visuals and optional DOF cabinet lighting.

### ▶️ Get started

**[Download the latest release »](https://github.com/PhosphorApp/phosphor/releases/latest)**

Extract the ZIP anywhere and run — everything is bundled and settings stay local for portability.

### 📦 Repositories

- **[phosphor](https://github.com/PhosphorApp/phosphor)** — the client app everyone runs (the host WPF app).
- **[phosphor-abstractions](https://github.com/PhosphorApp/phosphor-abstractions)** — the plug-in contract, published to NuGet as `Phosphor.Plugin.Abstractions`.
- **[phosphor-plugins](https://github.com/PhosphorApp/phosphor-plugins)** — the source plug-ins, packaged with the app at build time.
